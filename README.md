# Minecraft Server Setup Script

This script automates the initial setup of a Minecraft Java Edition server. It checks for prerequisites like Java and curl, downloads the official server JAR, automatically accepts the Minecraft EULA, and creates a basic `server.properties` file with common settings. It then provides clear instructions on how to start the server.

## Language

`bash`

## How to Run

1. Save the code as `setup_minecraft_server.sh`.
2. Make the script executable: `chmod +x setup_minecraft_server.sh`.
3. Run the script: `./setup_minecraft_server.sh`.
4. Follow the on-screen instructions to start the Minecraft server using the provided Java command.
